# Сложно сосредоточиться

Адаптивный учебный проект по HTML и CSS из курса Яндекс Практикума.

## Запуск
Откройте `index.html` в браузере. Сборка и установка зависимостей не нужны.

## Реализовано
- адаптивная вёрстка mobile-first на CSS Grid;
- светлая, тёмная и автоматическая темы;
- автоматическая тема учитывает `prefers-color-scheme`;
- выбранная тема сохраняется в `localStorage`;
- локальные шрифты, изображения и фавиконки;
- состояния наведения и клавиатурного фокуса;
- GitHub Actions для автотестов Яндекс Практикума.

## Структура
- `index.html` — разметка;
- `styles/variables.css` — переменные цветов и системная тема;
- `styles/globals.css` — базовые правила;
- `styles/style.css` — основная вёрстка и адаптив;
- `styles/dark.css`, `styles/light.css` — принудительные темы;
- `scripts/script.js` — переключение темы;
- `fonts/`, `images/` — локальные ресурсы;
- `.github/workflows/tests.yml` — автотесты.

## Загрузка в GitHub
Создайте **публичный** пустой репозиторий и из корня этой папки выполните:

```bash
git init
git add .
git commit -m "Complete focus project"
git branch -M main
git remote add origin https://github.com/ВАШ-ЛОГИН/ИМЯ-РЕПОЗИТОРИЯ.git
git push -u origin main
```

Замените URL на адрес созданного репозитория. Не создавайте в GitHub второй README, если загружаете этот файл.

## Перед сдачей
Workflow запускает проверку Практикума и намеренно завершится ошибкой, если репозиторий приватный. После `push` откройте вкладку **Actions** и посмотрите результат. Перед сдачей сравните внешний вид с макетом Figma и пройдите актуальный чек-лист курса: автоматические тесты не гарантируют пиксельное совпадение с макетом.
